# Java / Spring Boot Backend

Профиль с demo-проектами по backend-разработке на Java / Spring Boot.

## 🔧 Основные направления

- 🤖 **Telegram-боты для бизнеса** — сценарии общения, уведомления, хранение данных, интеграции
- 🔐 **Авторизация и роли доступа** — JWT, Spring Security, защищённые эндпоинты
- 🌐 **Backend-доработка** — REST API, PostgreSQL, исправление ошибок, новые функции
- 🧩 **Backend-проекты на микросервисах** — API Gateway, Eureka, миграции БД, сервисное взаимодействие

## 📌 Demo-проекты

### 🤖 Telegram Client Demo Bot

Demo-проект Telegram-бота на Java / Spring Boot.

Показывает backend-подход к разработке Telegram-бота:
сценарий взаимодействия с пользователем, работу с PostgreSQL, уведомления администратора, Docker-запуск и базовые тесты.

**Стек:**  
Java 17, Spring Boot, PostgreSQL, Flyway, Docker, JUnit 5, Mockito.

---

### 🔐 Spring JWT Auth Demo

Demo-проект backend-модуля авторизации.

Показывает настройку регистрации, авторизации, JWT, ролей доступа, защищённых эндпоинтов и документации API.

**Стек:**  
Java, Spring Boot, Spring Security, JWT, PostgreSQL, Flyway, Swagger / OpenAPI, Docker, тесты.

---

### 🏠 Real Estate Backend Demo

Многомодульный backend demo-проект сервиса недвижимости.

Показывает структуру backend-системы с отдельными модулями, REST API, бизнес-логикой, PostgreSQL, миграциями БД, сервисным взаимодействием, API Gateway и Eureka.

**Стек:**  
Java, Spring Boot, REST API, PostgreSQL, Flyway, Docker, API Gateway, Eureka, внешние API-интеграции.
